❓ Como usar o SuperProject

Escrever um projeto de uma vez

Uma linha por página, itens separados por hífen:

Página - tarefa 1 - tarefa 2 - tarefa 3

Exemplo

Resultado

📁 Configuração Inicial
   ☐ Instalar Node
   ☐ Instalar Expo

📁 Frontend
   ☐ Criar Login
   ☐ Criar Home

Regras

  • O primeiro texto antes do "-" vira o nome da página.
  • Cada item depois do "-" vira uma tarefa.
  • Cada linha cria uma nova página.
  • Você pode importar centenas de tarefas de uma vez.

Salvar e importar

  • Salvar → TXT gera a lista no mesmo formato de cima.
  • Salvar → JSON guarda tudo: fases, tipos, prazos, detalhes e OKRs.
  • Importar aceita arquivo TXT, arquivo JSON ou texto escrito na hora.

Visualizações

  • Lista — o checklist clássico, linha a linha.
  • Quadros — cartões lado a lado.
  • Kanban — colunas por fase, arraste para mudar.
  • Sprint — cada fase com progresso próprio.
  • Gantt — linha do tempo por semana ou mês.

Fases

  • Iniciação azul
  • Planejamento amarelo
  • Execução roxo
  • Review amarelo queimado
  • Fechamento verde

Dentro de cada item

Clique em ⋯ em qualquer item para abrir os detalhes. Lá dentro há abas:

  • Detalhes — descrição, prioridade, fase, tipo e prazo.
  • OKR Canvas — aparece quando o item é marcado como planejamento geral do projeto.
  • Kanban e Roadmap — para os demais itens, organizando as subtarefas por andamento ou por prioridade.

Datas

A data inicial e a escala ficam em "Editar projeto", na tela inicial. Dentro do projeto, o botão Mostrar datas ao lado do Gantt liga e desliga as datas no diagrama.
